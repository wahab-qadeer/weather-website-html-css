# Weather Website

A simple multi-page weather website developed using HTML and CSS to demonstrate web design and front-end development concepts.

## Features

- Multi-page website
- Weather-themed user interface
- Navigation between pages
- Responsive layout
- HTML and CSS styling

## Technologies Used

- HTML5
- CSS3

## Pages

- Home
- Weather
- About / Contact

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
